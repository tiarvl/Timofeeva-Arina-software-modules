Задание 6. Сохранение результатов
Контрольные вопросы
1.	Для чего используется блок-схема?
Ответ: Наглядное графическое представление алгоритма: видны действия, порядок и ветвления.
2.	Как обозначаются ввод, вычисление и условие?
Ответ: Ввод/вывод — параллелограмм; вычисление — прямоугольник; условие — ромб.
3.	Чем присваивание отличается от проверки равенства?
Ответ: Присваивание (S ← a + b) — это действие. Оно вычисляет выражение справа и записывает результат в переменную слева, заменяя её старое значение.
Проверка равенства (a > b) ?)— это вопрос, который не меняет значения переменных. Он лишь определяет, по какой ветке («Да» или «Нет») пойдет дальнейшее выполнение алгоритма.
4.	Чем следование отличается от ветвления?
Ответ: Следование — действия строго друг за другом; ветвление — выбор пути по условию, выполняется только одна ветвь.
5.	Может ли тело цикла с предварительной проверкой не выполниться ни разу?
Ответ: Да, если условие ложно при первой же проверке (например, N = 0).
6.	Для чего задают начальное значение накопителя?
Ответ: Начальное значение задаёт стартовое число для накопления. Без него первое S ← S + i прибавляет к неизвестному значению, и результат получается неверным. Для суммы берут S ← 0, потому что 0 не меняет сумму.
7.	Что может произойти без изменения счётчика цикла?
Ответ: Условие цикла никогда не станет ложным → бесконечный цикл
8.	Почему нужно проверять случай равных чисел?
Ответ: Потому что при равенстве нестрогое условие (≥) истинно, а строгое (>) ложно - это меняет выбранную ветвь, и проверка граничного случая выявляет ошибки.
9.	Что показывает таблица трассировки?
Ответ: Пошаговое выполнение алгоритма — позволяет вручную проверить алгоритм и найти ошибку.
10.	Почему успешной проверки на одном примере недостаточно?
Ответ: Он не проверяет все ветви, границы и особые случаи; успех на одном наборе не доказывает правильность для всех допустимых данных.
