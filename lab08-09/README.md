Контрольные вопросы
1.С чего начинается разработка блок-схемы по условию?
Ответ: С чтения условия: что дано и что требуется получить; затем выписываем входные/выходные величины.
2.Зачем указывать ограничения и единицы измерения?
Ответ: Ограничения показывают, какие данные допустимы. Единицы измерения придают результату физический смысл и не дают смешивать величины разных размерностей
3.Когда достаточно линейного алгоритма?
Ответ: Когда все действия выполняются последовательно, без выбора и повторений
4.Как выбрать условие для определения большего числа?
Ответ: Используется одно условие сравнения a > b. Если оно истинно, то большим является a, иначе - b.
5.Почему важно проверять значения ровно на границе диапазона?
Ответ: На границе диапазона чаще всего ошибки: строгое/нестрогое неравенство, неверный процент, лишний/пропущенный проход.
6.Как объединяются ветви перед общими действиями?
Ответ: Стрелки из всех ветвей сводятся в одну точку перед общим блоком - он выполнится ровно один раз.
7.Какие начальные значения нужны счётчику и накопителю?
Ответ: Счётчик - первое значение диапазона (i = 1), накопитель - нейтральное (S = 0).
8.Как проверить правильность количества повторений?
Ответ: Тестами N = 0, 1, 4 и трассировкой: считать проходы тела и проверки условия.
9.Чем ожидаемый результат отличается от результата трассировки?
Ответ: Ожидаемый считается независимо (по формуле/смыслу), трассировка - пошаговым выполнением схемы.
10.Какие материалы этой работы можно использовать при последующем написании программы?
Ответ: Таблицы входных, выходных и промежуточных величин с их ограничениями и единицами; сами блок-схемы; подобранные тестовые данные с ожидаемыми результатами.
