А. Через do…while вычисляйте квадрат int от −1000 до 1000; после каждого результата спрашивайте «Ещё? д/н». Только «д» продолжает.
Код:
static void Main(string[] args)
 {
         string answer;
         do
         {
             int number;
             bool valid;
             do
             {
                 Console.Write("Введите целое число от -1000 до 1000: ");
                 string input = Console.ReadLine();
                 if (input == null)
                 {
                     Console.WriteLine("Ввод завершён");
                     return;
                 }
                 valid = int.TryParse(input, out number)
                 && number >= -1000 && number <= 1000;
                 if (!valid)
                     Console.WriteLine("Нужно целое число от -1000 до 1000.");
             }
             while (!valid);
             long square = (long)number * number; // long — защита от переполнения
             Console.WriteLine($"Квадрат {number} = {square}");
             Console.Write("Ещё? д/н: ");
             answer = Console.ReadLine();
             if (answer == null)
             {
                 Console.WriteLine("Ввод завершён");
                 return;
             }
         }
         while (string.Equals(answer, "д", StringComparison.OrdinalIgnoreCase));
         Console.WriteLine("Работа завершена.");

Б. Калькулятор перевода градусов Цельсия в Фаренгейты обслуживает хотя бы один запрос и предлагает повтор после каждого результата. Используйте F = 1,8C + 32, −100 ≤ C ≤ 100.
Код:
    static void Main(string[] args)
    {
        string answer;
        do
        {
            decimal celsius;
            bool valid;
            do
            {
                Console.Write("Температура в °C (от -100 до 100): ");
                string input = Console.ReadLine();
                if (input == null)
                {
                    Console.WriteLine("Ввод завершён");
                    return;
                }
                // Разрешаем дробные значения: 36,6 и т.п.
                valid = decimal.TryParse(input, out celsius)
                        && celsius >= -100m && celsius <= 100m;
                if (!valid)
                    Console.WriteLine("Нужно число от -100 до 100.");
            }
            while (!valid);
            decimal fahrenheit = 1.8m * celsius + 32m;
            Console.WriteLine($"{celsius} °C = {fahrenheit} °F");
            Console.Write("Ещё? д/н: ");
            answer = Console.ReadLine();
            if (answer == null)
            {
                Console.WriteLine("Ввод завершён");
                return;
            }
        }
        while (string.Equals(answer, "д", StringComparison.OrdinalIgnoreCase));
        Console.WriteLine("Калькулятор закрыт.");

Контрольные вопросы
1.	Почему тело do…while выполняется хотя бы один раз?
Ответ: Потому что проверка условия стоит после тела цикла. Сначала выполняется тело, и только потом проверяется условие продолжения. Даже если условие сразу ложно, один проход уже состоялся.
2.	Что означает true в постусловии?
Ответ: true означает «продолжать цикл.
3.	Зачем нужна точка с запятой после while?
Ответ: Это синтаксис C#: конструкция do...while завершается точкой с запятой, потому что это один составной оператор.
4.	Почему переменную условия объявляют перед do?
Ответ: : Потому что она используется в условии while после тела цикла. Если объявить её внутри { }, она будет видна только внутри тела, а в while — нет.
5.	Как TryParse помогает повторно запрашивать ввод?
Ответ: TryParse возвращает bool, который записывается в переменную-флаг (valid), объявленную до цикла; условие while (!valid) заставляет тело выполняться заново всякий раз, когда разбор или проверка диапазона не удались, — и цикл прекращается только когда пользователь ввёл корректное значение.
6.	Почему для цифр числа 0 подходит do…while?
Ответ: do...while гарантирует первый проход. Благодаря этому для числа 0 цикл один раз посчитает цифру 0, тогда как обычный цикл её пропустит.
7.	Как ограничить число попыток?
Ответ: Ввести счётчик попыток и добавить его в условие продолжения
8.	В каких задачах этот цикл менее удобен, чем for?
Ответ: Когда число повторений известно заранее или первый проход не обязателен. Например, для вывода чисел от 1 до n при n = 0 цикл do...while сделает лишний проход, а for корректно не выполнится ни разу.
